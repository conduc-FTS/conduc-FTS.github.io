FTS · Test d'écriture sur le serveur
Page de test uniquement, à ouvrir dans Chrome ou Edge sur un PC du bureau qui voit le lecteur P:.
Rien ne part sur internet : le navigateur lit et écrit directement sur le serveur, avec les droits de la session Windows. Le test n'écrit que dans un dossier _TEST_DASHBOARD créé dans le chantier choisi, et le supprime à la fin.
1
Navigateur compatible
2
Relier le dossier des chantiers

Clique, puis va dans P:\PARTAGE\FTS\7 - TRAVAUX\7-1 - CHANTIERS EN COURS et clique « Sélectionner un dossier ». Le navigateur demandera ensuite « Autoriser les modifications » : accepte.

3
Retrouver le chantier par son code

Recherche les dossiers dont le nom commence par le code, avec ou sans espaces (« 26 FTS 099 » = « 26FTS099 »).

    4
    Lire les sous-dossiers du chantier
      5
      Écrire puis relire un fichier test

      Crée _TEST_DASHBOARD dans le chantier, y écrit un petit fichier texte et un petit PDF, puis les relit pour vérifier.

      6
      Nettoyer

      Va d'abord voir dans l'Explorateur que le dossier _TEST_DASHBOARD et ses 2 fichiers sont bien là. Ensuite, supprime-le d'ici.
